# Radio RMF

Nieoficjalny odbiornik stacji RMF (RMF FM, RMF MAXX, RMF Classic, RMF Classic Rock) i kanałów RMF ON.

- **W przeglądarce / na telefonie:** https://zooolw-sudo.github.io/radio-rmf/ (można dodać do ekranu głównego)
- **Na Androida (radio samochodowe, telefon):** [pobierz radio-rmf.apk](https://github.com/zooolw-sudo/radio-rmf/releases/latest/download/radio-rmf.apk)

Wersja na Androida gra w tle (np. przy włączonej nawigacji), obsługuje przyciski na kierownicy i przycisza się przy komunikatach nawigacji.

APK buduje się sam po każdej zmianie w gałęzi `main` (GitHub Actions → zakładka Releases).
